# 🚀 Reflex7 - Elite Edition

[TR] Reflekslerinizi ve zeka hızınızı test eden, yüksek tempolu bir odaklanma oyunu.  
[EN] A high-paced focus game that tests your reflexes and cognitive speed.

---

## 🕹️ Oyun Hakkında / About The Game

**[TR]** Reflex7, oyuncuyu saniyeler içinde karar vermeye zorlayan bir hyper-casual web oyunudur. Sadece bir butona basmak kadar basit görünse de; dinamik matematik bulmacaları, görsel tuzaklar ve hafıza oyunlarıyla zihninizi zorlar. 

**[EN]** Reflex7 is a hyper-casual web game that forces players to make split-second decisions. While it seems simple, it challenges your mind with dynamic math puzzles, visual traps, and memory tasks.

---

## ✨ Özellikler / Features

- ⚡ **İki Mod / Two Modes:** Yavaş (7sn) & Hızlı (4sn) seçenekleri.
- 🧠 **Zeka Görevleri / Smart Tasks:** Matematik işlemleri (negatif sonuç tuzaklı!), kelime analizleri ve emoji tuzakları.
- 💾 **Rekor Sistemi / High Score:** En yüksek seviyeniz tarayıcıda (`localStorage`) saklanır.
- 📉 **Dinamik Zorluk / Dynamic Difficulty:** Her 5 seviyede bir oyun hızlanır!
- 🫨 **Hata Efekti / Shake Effect:** Yanlış hamlede ekran sarsıntısı ile gerçekçi geri bildirim.
- 📱 **Modern UI:** CSS Flexbox ile mükemmel merkezlenmiş, göz yormayan karanlık tema.
